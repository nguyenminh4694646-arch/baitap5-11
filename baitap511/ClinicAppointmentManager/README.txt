CLINIC APPOINTMENT MANAGER

Yeu cau:
- Windows 10/11
- Visual Studio 2022
- Workload: .NET desktop development
- .NET 8 SDK

Cach mo va chay:
1. Giai nen file ZIP.
2. Mo file ClinicAppointmentManager.csproj bang Visual Studio 2022.
3. Neu Visual Studio hoi tai .NET SDK thi cai .NET 8.
4. Chon Debug / Start Without Debugging (Ctrl + F5).

Chuc nang:
- Them, cap nhat, xoa lich hen co xac nhan.
- Chon mot dong tren bang de nap du lieu len form.
- Tim kiem tuc thoi theo ten benh nhan hoac so dien thoai.
- Loc theo ngay hen va trang thai.
- Kiem tra truong bat buoc, so dien thoai va ngay hen khong o qua khu.
- Xuat danh sach dang hien thi sau loc ra CSV.
- StatusStrip hien so lich hen sau loc.

Luu y:
- Du lieu hien duoc luu trong bo nho khi chuong trinh dang chay; dong ung dung se mat du lieu.
- Bai tap yeu cau BindingList va BindingSource, khong bat buoc co co so du lieu.
